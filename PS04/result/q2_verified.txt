----- 4.1 symbol table : the global x is a GLOBAL symbol, the local x has no symbol at all -----
$ nm q2_extern_nopie   | grep -w x           # 'D' upper case = external linkage
0000000000404018 D x
$ nm q2_noextern_nopie | grep -w x           # the global x is still there, unchanged
0000000000404020 D x

$ readelf -s q2_extern_nopie | grep -w x     # OBJECT, GLOBAL, 4 bytes, in .data
    21: 0000000000404018     4 OBJECT  GLOBAL DEFAULT   25 x

(compare with Q1: the static y was 'd' lower case = local, no other file can see it)
