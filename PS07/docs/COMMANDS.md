# PS07 — คำสั่งที่ต้องพิมพ์เองใน terminal และภาพหน้าจอที่ต้องถ่าย

เอกสารนี้ไม่ใช่รายงาน แต่เป็น script การทำงานร่วมกัน: **คุณพิมพ์คำสั่งใน terminal เอง**
แล้วพิมพ์ชื่อภาพ (เช่น `t02`) มาในแชต → Claude จะถ่ายภาพหน้าต่างนั้นให้ เซฟลง
`PS07/result/screenshots/` ตัดขอบภาพด้วย `PS06/tools/crop_shot.ps1` แล้วเปิดดูเพื่อยืนยันว่าภาพใช้ได้ก่อนไปขั้นถัดไป
ตัวเลขทุกตัวในรายงานอ่านจากภาพเหล่านี้เท่านั้น

## เตรียมตัวก่อนเริ่ม

1. เปิด **Windows Terminal → Ubuntu (WSL)** ให้หน้าต่างอยู่หน้าสุด และ **ขยายหน้าต่างให้กว้าง**
   (maximize ได้ยิ่งดี) เพราะผลแต่ละรอบพิมพ์เป็นบรรทัดเดียวยาวประมาณ 100 ตัวอักษร
   ถ้าหน้าต่างแคบ บรรทัดจะถูกตัดขึ้นบรรทัดใหม่และอ่านยาก
2. ขยาย font ให้ใหญ่พอ: กด `Ctrl` + `Shift` + `+` ประมาณ 1–2 ครั้ง แล้วเช็กว่าบรรทัดผลลัพธ์
   ยังไม่ถูกตัด (ถ้าถูกตัด ให้ลด font ลงหนึ่งขั้นด้วย `Ctrl` + `-`)
3. เข้าไปที่ folder ของโปรแกรมครั้งเดียวก่อนเริ่ม:

   ```bash
   cd /mnt/c/Users/Oping/CPE333_OS/PS07/src
   ```

4. ทุกคำสั่งด้านล่างขึ้นต้นด้วย `clear;` แล้ว เพื่อให้ในภาพเห็นเฉพาะคำสั่งของขั้นนั้น
5. ถ้าเจอปัญหา/error ให้พิมพ์ `err <ข้อความ>` มาในแชต Claude จะบันทึกไว้ใน
   `PS07/result/notes.txt` และเขียนเป็นหัวข้อ "ปัญหาที่พบ" ในรายงาน

> ผลของข้อ 2 และข้อ 3 **ไม่มีทางได้ตัวเลขเดียวกับตัวอย่างในเอกสารนี้** เพราะนั่นคือสิ่งที่
> การทดลองต้องการแสดง (non-deterministic) ไม่ต้องรันซ้ำเพื่อให้ได้ตัวเลขสวย ๆ

## Task 1 — รันด้วย thread เดียว เพื่อยืนยันว่าโปรแกรมถูกต้อง (ภาพ t01–t02)

### t01 — สภาพแวดล้อมและการคอมไพล์ตามคำสั่งในใบงาน

```bash
cd /mnt/c/Users/Oping/CPE333_OS/PS07/src; clear; nproc; gcc --version | head -1; gcc -o ps7 ps7.c -lpthread; ls -l ps7
```

ใส่ `cd` ไว้ในคำสั่งนี้ด้วย เพราะถ้าเปิด terminal ใหม่ shell จะเริ่มที่ home (`~`) และ gcc จะฟ้อง
`cc1: fatal error: ps7.c: No such file or directory` (เจอจริงในการถ่ายครั้งแรก)

ต้องเห็น: `22` (จำนวน CPU), `gcc ... 13.3.0`, คอมไพล์ผ่านโดยไม่มีข้อความใด ๆ และไฟล์ `ps7`
ที่รันได้ (สิทธิ์มี `x`)

### t02 — รันด้วย thread เดียว 5 รอบ

```bash
clear; for i in $(seq 5); do ./ps7 1 1000000; done
```

ต้องเห็น: 5 บรรทัด ทุกบรรทัดเป็น `in=1000000 out=1000000 | expected=1000 actual=1000 diff=+0 OK`
คือ thread เดียวฝากเงิน 1,000,000 ครั้งแล้วถอน 1,000,000 ครั้ง ยอดเงินกลับมาที่ 1,000 บาทพอดีทุกรอบ
